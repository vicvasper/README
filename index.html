Plugins and systems

OmegaTeller

Unreal Engine 5.8 · Experimental

Narrative design tool that turns a game design document into per-character branching story trees, edited as a node graph inside an embedded web view. A bundled local LLM keeps merges, splits and rewrites narratively coherent without any cloud dependency.

C++SlateLocal LLM

Kinemotion

Unreal Engine 5.5+

Markerless motion capture. Runs pose inference on the GPU through NNE with a DirectML backend, decodes 133 keypoints into a 19-bone skeleton, and streams it into the engine over a custom Live Link source. Auto-calibration, anti-jitter filtering and multiplayer support.

C++NNE / DirectMLLive Link

Optilogger

Unreal Engine 5.3+

Editor plugin that audits an entire level in one pass: static and skeletal meshes, textures, materials, animations, audio, lighting and post-process. Estimates memory, counts shader instructions, narrows the scan with frustum culling and exports JSON reports. Built on Slate, hotkeys for every category.

C++SlateProfiling

SmartFolders

Unreal Engine 5.6

Content Browser organizer driven by rules. Two modes, type-based and name-grouping, with Epic-recommended presets, batch operations and full undo. Written after one too many afternoons sorting assets by hand.

BlueprintsPythonEditor

Paint System

Unreal Engine 5.4

Runtime vertex-colour painting for static and skeletal meshes, with per-channel RGBA control, configurable fade, GPU-batched updates and a Blueprint API.

C++Render targetsMaterials

Procedural Animated System

Unreal Engine 5.5

Line-traces the terrain and spawns spline bridges, wall ladders or stepped ramps depending on the surface normals it finds. Spawns at runtime and comes out animation-ready.

C++SplinesPCG

Grass Generator

Unreal Engine 5.3

Landscape tool for filling and painting grass layers across large terrains, with control over distribution, density and blending.

C++Landscape
