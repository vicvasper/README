Plugins y sistemas

Kinemotion

UE 5.5+

Markerless motion capture. Runs pose inference on the GPU through NNE, decodes 133 keypoints into a 19-bone skeleton and streams it into Unreal over a custom Live Link source.

C++ · NNE / DirectML · Live Link

Optilogger

UE 5.3+

Editor plugin that audits a whole level in one pass: meshes, textures, materials, animations, audio, lighting and post-process. Memory estimation, shader instruction counts, frustum culling and JSON export.

C++ · Slate · Profiling

SmartFolders

UE 5.6

Rule-driven Content Browser organizer. Type-based and name-grouping modes, Epic-recommended presets, batch operations and full undo.

C++ · Python · Editor

Paint System

UE 5.4

Runtime vertex-colour painting for static and skeletal meshes, per-channel RGBA, configurable fade, GPU-batched updates and a Blueprint API.

C++ · Render targets · Materials

Procedural Animated System

UE 5.5

Terrain-aware generator that line-traces the ground and spawns spline bridges, wall ladders or stepped ramps from the surface normals. Animation-ready, spawns at runtime.

C++ · Splines · PCG
